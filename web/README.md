# web/

## models in the gallery

`web/model/` is gitignored and regenerated by `tools/export_web_models.sh`,
which copies the checkpoint directories it is given (each holding
`model.safetensors` and `config.json`) and writes `web/model/index.json`,
which the model picker reads. Run it before opening the page locally:

```
./tools/export_web_models.sh model20=models/model20
```
