## Comparability with the Eulerian (shallow-water) bars

**Not comparable as a pass/fail against the Eulerian acceptance bars**
(corr@25≥0.9, corr@50≥0.8, amp-ratio@50∈[0.7,1.3]):

- The Lagrangian pipeline (SPH → splat → grid model) has a much shorter
  history: this is explicitly a *smoke* checkpoint, not one trained to the
  standard/stress protocol's step budget or 70/30 mixture that model20 used.
- The domain is physically different (weakly-compressible SPH dam
  break/drop vs. shallow-water single-drop waves): amplitude ratios near
  10-15x indicate the model has not learned the SPH-splatted dynamics at
  all yet at 25 ticks, consistent with under-training rather than an
  architecture or metric bug (the same `correlation`/`decode_h` functions
  are shared, unit-tested code paths already used and passing on the
  Eulerian side).
- Read these numbers as "the Lagrangian training path works end-to-end and
  produces a finite, scoreable rollout" (the goal doc's minimum bar for this
  phase), not as evidence the Lagrangian model has converged.
